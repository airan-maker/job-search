# Recruiter Agent

**채용의 모든 과정을 AI가 도와드립니다**

HR 담당자, 채용 담당자, 헤드헌터를 위한 AI 채용 도우미입니다.

## 주요 기능

### 1. JD (Job Description) 작성
- 새 JD 작성 (포지션별 맞춤 템플릿)
- 기존 JD 개선 (포용적 언어 검토 포함)
- 경쟁사 JD 벤치마킹 (실시간 웹 검색)
- JD 체크리스트

### 2. 후보자 소싱 전략
- 타겟 페르소나 정의
- 소싱 채널 전략 (LinkedIn, GitHub, 커뮤니티 등)
- 아웃리치 메시지 템플릿
- 추천 채용 프로그램 설계

### 3. 면접 설계
- 면접 질문 생성 (인성/기술/임원)
- 평가 기준표 (Rubric) 생성
- 면접관 가이드
- 기술 면접 설계 (라이브 코딩, 시스템 설계)

### 4. 후보자 평가
- 이력서 스크리닝 체크리스트
- 후보자 비교 분석
- 레퍼런스 체크 가이드
- 오퍼 협상 가이드

### 5. 채용 브랜딩
- 회사 소개 페이지 카피
- 채용 공고 홍보 콘텐츠
- 채용 설명회 자료
- 후보자 경험 개선 가이드

## 설치 및 실행

```bash
# 의존성 설치 (루트에서)
npm install

# 실행
npm run dev:recruiter

# 또는 직접 실행
cd packages/recruiter-agent
npm run dev
```

## 환경 변수

```bash
export ANTHROPIC_API_KEY="your-api-key"
```

## 회사 정보 설정

처음 실행 시 "🏢 회사 정보 설정"에서 회사 정보를 입력하면 더 맞춤화된 콘텐츠를 생성할 수 있습니다.

- 회사명
- 산업
- 규모
- 단계 (스타트업/성장기/대기업)
- 회사 문화 키워드
- 복지/혜택
- 기술 스택
- 미션

## 출력 파일

생성된 콘텐츠는 `output/` 폴더에 마크다운 형식으로 저장됩니다.

## Job Search Agent와의 연계

| Recruiter Agent | Job Search Agent |
|-----------------|------------------|
| JD 작성 | JD 분석 |
| 면접 질문 생성 | 면접 답변 준비 |
| 후보자 평가 기준 | 합격률 분석 |
| 연봉 벤치마크 | 연봉 협상 가이드 |

양쪽 관점을 이해하면 더 나은 채용/이직이 가능합니다!

## 기술 스택

- **Runtime**: Node.js + TypeScript
- **AI/LLM**: Claude API (Anthropic) + Web Search
- **CLI**: Commander + Inquirer
