# Job Search Agent

**내 정보는 비공개, 채용 공고는 AI가 찾아준다**

프라이버시를 지키면서 이직을 준비할 수 있는 AI 에이전트입니다.

## v3.0 새로운 기능

- **실시간 코칭 면접**: 답변마다 즉각적인 피드백을 받는 모의 면접
- **합격률 분석**: 프로필과 JD 매칭 분석, Gap 분석, 맞춤형 개선 전략
- **연봉 협상 가이드**: 시장 연봉 분석, 협상 시나리오별 스크립트, 복리후생 협상 포인트
- **종합 이직 전략**: 전체 지원 현황 분석 및 액션 플랜

## v2.0 기능

- **실시간 웹 검색**: 실제 채용 사이트에서 공고를 검색합니다
- **PDF 내보내기**: 생성된 이력서/자소서를 PDF로 저장합니다
- **지원 현황 대시보드**: 지원 상태를 한눈에 확인합니다
- **회사 리서치 강화**: 웹 검색으로 최신 회사 정보를 수집합니다

## 주요 기능

### 1. 프로필 관리
- 마스터 프로필 생성 및 편집
- 로컬 JSON 파일로 안전하게 저장
- AI 기반 프로필 분석 및 개선 제안

### 2. AI 채용 공고 자동 탐색 ⭐
- 프로필 기반 검색 쿼리 자동 생성
- **실시간 웹 검색**으로 실제 채용 공고 탐색
- AI 추천 모드로 맞춤 공고 제안
- 매칭 스코어 산출 및 추천 이유 설명
- 관심 공고 저장 및 관리

### 3. 맞춤 이력서 생성
- 선택한 공고의 JD 분석
- 공고에 최적화된 이력서 자동 생성
- 자기소개서 작성 지원
- **PDF 내보내기**

### 4. 면접 준비 코치
- 예상 질문 생성 (인성/기술/경험)
- AI 면접관과 모의 면접
- **실시간 코칭 면접**: 답변마다 즉각적인 피드백
- 답변 피드백 및 개선점 제안
- **실시간 웹 검색**으로 회사 최신 정보 수집

### 5. 전략 분석 ⭐
- **합격률 분석**: 프로필-JD 매칭, Gap 분석, 합격 가능성 예측
- **연봉 협상 가이드**: 시장 연봉, 협상 스크립트, 복리후생 협상
- **종합 이직 전략**: 전체 지원 현황 분석 및 주간 액션 플랜

### 6. 지원 현황 대시보드
- 상태별 통계 (저장/지원/면접중/합격/불합격)
- 최근 활동 타임라인
- 매칭 점수 분포
- 진행 중인 지원 현황

## 사용 방법

1. **프로필 생성**: 경력, 기술 스택, 희망 조건 입력
2. **채용 공고 탐색**: AI가 프로필에 맞는 공고를 자동으로 검색
   - 실시간 웹 검색: 실제 채용 사이트에서 공고 검색
   - AI 추천: 프로필 기반 맞춤 공고 제안
3. **관심 공고 저장**: 마음에 드는 공고를 저장
4. **이력서 생성**: 저장한 공고에 맞춤화된 이력서 생성 → PDF 내보내기
5. **면접 준비**: 예상 질문 확인 및 모의 면접 연습
6. **대시보드**: 지원 현황 한눈에 확인

## 프로젝트 구조

```
src/
├── index.ts              # CLI 메인 엔트리
├── agents/
│   ├── profile-agent.ts  # 프로필 관리
│   ├── job-search-agent.ts # 채용 공고 탐색 + 대시보드
│   ├── resume-agent.ts   # 이력서 생성 + PDF
│   ├── interview-agent.ts # 면접 준비 + 코칭
│   └── strategy-agent.ts # 전략 분석 (합격률/연봉협상)
├── storage/
│   └── index.ts          # 로컬 데이터 저장
├── types/
│   └── index.ts          # TypeScript 타입 정의
└── utils/
    ├── index.ts          # 유틸리티 함수
    └── pdf-generator.ts  # PDF 생성
```

## 기술 스택

- **Runtime**: Node.js + TypeScript
- **AI/LLM**: Claude API (Anthropic) + Web Search
- **CLI**: Commander + Inquirer
- **PDF**: PDFKit
- **Storage**: Local JSON
